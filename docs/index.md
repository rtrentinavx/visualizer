# Visualizer

Aviatrix DCF topology visualizer.

## Overview

Import your Aviatrix Data Center Fabric (DCF) configuration and explore an interactive visual representation of your network topology.

## Features

- DCF configuration import
- Interactive topology graph
- Node and link visualization
- Export diagrams

## Getting Started

Visit the [live app](https://dcf-visualizer.vercel.app) and import your DCF configuration.
